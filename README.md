# RAG Document Chunking Pipeline — Local-First Semantic Search & QA Platform

**RAG Document Chunking Pipeline** is a full-stack, local-first Retrieval-Augmented Generation (RAG) workspace that lets users securely register, upload documents (PDF, DOCX, TXT, MD, CSV), parse and chunk text into dense vector embeddings, and ask natural-language questions grounded strictly in their private files—complete with source citations, document indexing status tracking, and zero cloud LLM API costs.

---

## Key Features

- **End-to-End Ingestion & Chunking Pipeline:** Extracts text from multi-format documents (`pypdf`, `python-docx`), splits content into structured chunks, generates 384-dimensional dense embeddings via **Sentence-Transformers (`all-MiniLM-L6-v2`)**, and indexes payloads in **persistent on-disk Qdrant**.
- **Grounded Answers & Source Citations:** Displays answers generated by local **Ollama (`Qwen2.5:3b`)** alongside expandable `Sources` sections beneath responses so reviewers can inspect the underlying document context.
- **Unified ChatGPT-Style Workspace:** Single-page dark-themed interface (`React`, `TypeScript`, `Vite`, `Tailwind CSS`) featuring a live stack status pill (`Qwen2.5:3b · MiniLM-L6 · Qdrant`), file counter (`7 files · 5 ready`), `Private` workspace badge, sidebar chat history, `Workspace files` drawer with `Ready` indexing states, and one-click response copy controls.
- **Zero-Infrastructure Local Execution (No Docker, WSL, or External DB Server):** Runs completely offline on Windows, macOS, or Linux using **Ollama (`Qwen2.5:3b`)**, embedded **SQLite**, and file-based **Qdrant (`./qdrant_data`)**.
- **Dual-Database Architecture & User Isolation:**
  - **SQLite (SQLAlchemy ORM):** Manages user accounts, JWT Bearer authentication (`Passlib` / `bcrypt`), document ownership, and indexing lifecycle metadata with zero external database setup.
  - **Qdrant (Local Disk Storage):** Stores chunk vectors and metadata payloads scoped strictly to the authenticated user.

| **Frontend** | React, TypeScript, Vite, Tailwind CSS |
| **Backend** | Python, FastAPI, Uvicorn, Pydantic v2, SQLAlchemy, Passlib (`bcrypt`), JWT |
| **AI / Chunking & RAG** | Ollama (`qwen2.5:3b`), Sentence-Transformers (`all-MiniLM-L6-v2`), `pypdf`, `python-docx` |
| **Databases & Storage** | SQLite (Relational Metadata & Auth), Qdrant (Persistent Local Vector Store) |
